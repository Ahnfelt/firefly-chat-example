# firefly-chat-example

An example of how to structure a webapp in Firefly.

It demonstrates the following features:

 - Webserver
 - Assets
 - Server sider rendering
 - Hydration and client side rendering
 - Styling
 - Event handling
 - Loading status (useSuspense)
 - Error handling (TODO)
 - Form validation (TODO)
 - Routing with type safe links
 - Per-route bundling with treeshaking
 - Type safe AJAX/RPC
 - Websockets (client + server)
 - Database
 - Date handling


Possible extensions for later:
 - Session handling
 - Sign in and out
 - Restore password
 - Send emails
 - 2FA
